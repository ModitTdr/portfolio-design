# 02 — Overview

## Making grocery spending easier to understand

Grocery shopping involves more than simply deciding what to buy.

People need to plan purchases, estimate costs, stay within a budget, and understand where their money goes over time.

SmartGroceries brings budgeting, grocery planning, shopping, and purchase history into one experience.

This is a self-directed UI/UX practice project exploring an end-to-end product design process.

Visually, consider making this section **typography-led** rather than using another generic card.

Use a strong statement or oversized typography for the key idea:

**“People don't necessarily need to plan more. They need to see their spending more clearly.”**

# Visual & Interaction Requirements

## 1. Do not make every section look identical

Create rhythm throughout the page.

Alternate between:

* Typography-led sections
* Full-width UI showcases
* Split layouts
* Large visual compositions
* Minimal text sections
* Horizontal visual sequences
* Asymmetric layouts where appropriate

The page should feel **art-directed**, not assembled from repeated cards.

---

## 2. Use whitespace intentionally

The design should breathe.

Do not try to fit too much information above the fold.

Use large spacing between major ideas and tighter spacing within related information.

---

## 3. Typography should do significant storytelling

Use the existing portfolio typography system.

Create moments of:

* Oversized statements
* Small metadata
* Strong section numbers
* Large project titles
* Short highlighted phrases

Avoid paragraphs becoming the dominant visual element.

---

## 4. Product visuals are the hero

The actual SmartGroceries interface should receive more visual attention than decorative elements.

Use:

* Large screenshots
* Cropped UI details
* Device/browser compositions if they fit the existing aesthetic
* Layered screens
* Subtle depth
* Scroll-based reveals

Do not add random decorative graphics simply to make the page look “creative.”

---

## 5. Motion

Use the existing site's motion language.

Motion should feel:

**subtle · smooth · intentional**

Consider:

* Text reveal
* Image reveal
* Scroll-triggered transitions
* Parallax where appropriate
* Sticky visual sections
* Subtle scale/opacity transitions
* Page transition from the project listing into the case study

Do not over-animate the page.

Performance and accessibility should take priority.

Respect `prefers-reduced-motion`.

---

## 6. Dark aesthetic

The page should maintain the existing dark portfolio aesthetic.

Use contrast carefully.

Avoid:

* Excessive gradients
* Neon colors
* Glassmorphism everywhere
* Excessive shadows
* Generic AI-generated decorative elements

The design should feel **quiet, confident, and premium**.

---

## 7. Responsive Design

The case study must work exceptionally well across:

* Desktop
* Tablet
* Mobile

Do not simply shrink the desktop layout.

Reconsider hierarchy and composition for smaller screens.

Especially review:

* Large typography
* Horizontal layouts
* Sticky elements
* Image crops
* Navigation
* Spacing
* Project metadata

---
